Acerca de NewsWave

NewsWave es una plataforma web de noticias desarrollada como proyecto del módulo de Desarrollo de Front-end. El aplicativo permite explorar publicaciones de seis categorías, consultar el detalle de cada noticia y comunicarse con la redacción por medio de un formulario.

Cómo está construido

Esta versión corresponde a la Entrega 2 y cubre el desarrollo en HTML, CSS y JavaScript, junto con el renderizado dinámico del catálogo desde un archivo JSON local. No se utilizan librerías externas.

  • HTML5 semántico: se emplean las etiquetas header, nav, main, section, article, aside y footer.
  • CSS: variables para el sistema de diseño, CSS Grid para las retículas y Flexbox para los componentes internos.
  • JavaScript: carga del archivo JSON con fetch y generación dinámica de las tarjetas, los filtros, la búsqueda y la paginación.
  • Diseño responsivo: tres puntos de quiebre para escritorio, tableta y dispositivos móviles.

Contenido

Las noticias y las imágenes que se muestran son material de demostración creado para el ejercicio académico y no corresponden a hechos reales.

Siguientes pasos

En los puntos restantes de la entrega se implementarán la gestión de favoritos con almacenamiento en el navegador, las validaciones del formulario de contacto y la publicación del proyecto en un repositorio de GitHub.
